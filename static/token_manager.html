⛔ Token is Expired / Invalid
The last auto-renewal got a 401 from Dhan — the current token cannot be renewed.

Fix options (choose one):
  1. Generate a fresh token on dhan.co → My Profile → Access Token.
  2. Paste it into .env → ACCESS_TOKEN=eyJ0eX… → click "Reload from .env" below (no server restart needed).
  3. Or paste it directly into the "Set Token" box below.

⚙️ How Auto-Renewal Works

1
Renewal runs every weekday at 09:00 AM IST (18-hour interval). Weekends are skipped — the job waits until the next Monday.
2
On renewal the new token is written to .env, loaded into memory, and all API calls immediately use it.
3
If the token is expired/invalid (401), automatic retries stop. Paste a fresh token and click Reload from .env or use Set Token below.
